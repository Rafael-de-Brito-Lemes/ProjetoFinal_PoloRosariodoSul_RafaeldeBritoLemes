# Sistema Administrativo de uma Loja de Instrumentos Musicais

## Sobre o projeto

Sistema web desenvolvido como projeto final da disciplina de Desenvolvimento Back End. O objetivo é permitir o gerenciamento de instrumentos musicais, categorias e fornecedores de uma loja.

## Tecnologias utilizadas

- Node.js
- Express
- EJS
- MongoDB Atlas
- Mongoose
- Bootstrap 5

## Funcionalidades

O sistema possui três módulos principais:

### Instrumentos
- Cadastro de instrumentos.
- Listagem dos instrumentos cadastrados.
- Visualização dos detalhes.
- Edição de registros.
- Exclusão de registros.
- Pesquisa pelo nome.

### Categorias
- Cadastro de categorias.
- Listagem de categorias.
- Visualização dos detalhes.
- Edição e exclusão.
- Pesquisa pelo nome.

### Fornecedores
- Cadastro de fornecedores.
- Listagem de fornecedores.
- Visualização dos detalhes.
- Edição e exclusão.
- Pesquisa pelo nome.
